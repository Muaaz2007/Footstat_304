# Data folder

This folder documents where the project's data lives. The data files themselves are kept
with the subsystem that owns them, so there is one copy of each file rather than duplicates
that drift apart.

| Data | Location | Produced by |
| --- | --- | --- |
| Raw player dataset (`fifa_players.csv`) | `ai-core/data/raw/` | Supplied with the project; not committed |
| Cleaned modelling dataset (`players_clean.csv`) | `ai-core/data/processed/` | `ai-core/ai/preprocessing.py` |
| Prediction and evaluation table (`player_predictions.csv`) | `ai-core/outputs/` | `ai-core/ai/predict_evaluate.py` |
| Model comparison and error outputs | `ai-core/outputs/` | `ai-core/ai/train_compare.py` |

## Flow

```
raw dataset -> preprocessing -> processed dataset -> model training
             -> predictions and evaluations -> backend API -> dashboard
```

The backend does not read the raw or processed dataset. It reads only
`player_predictions.csv`, because that is the file the interface document defines as the
hand-off between the AI subsystem and the rest of the system.

## Why the data is not copied here

`player_predictions.csv` is about 2.6 MB and is regenerated by the AI pipeline. Copying it
into several folders would mean several versions of the same table, with no way to tell
which one is current. Keeping a single source of truth keeps the system honest: if the
numbers on the dashboard look wrong, there is exactly one file to check.

## Notes on the data

- The dataset describes 17,954 players. 17,699 have a recorded market value; 255 do not.
- The recorded value is treated as the available reference, not as a live market price.
  The reasoning and the tradeoff used instead are in
  `ai-core/MARKET_VALUE_LIMITATION_AND_STRATEGY.md`.
- Large generated files, such as the trained model, are excluded through `.gitignore` and
  can be recreated by running the pipeline.
